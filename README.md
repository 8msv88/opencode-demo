# opencode-demo

A tiny demo proving the **browser → OpenCode (running on my PC) → GitHub** loop.

## What it is

A single-page static site (`index.html`) with a click counter. No build step.

## Run it

Open `index.html` in any browser.

## How this got here

1. Prompted OpenCode from the browser web UI (server running on my PC, LAN-accessible).
2. OpenCode created these files locally.
3. OpenCode created this GitHub repo and pushed via `gh`.

That is the full workflow, end to end.
